Kubernetes 真实集群执行（概念解析）

目标

理解 Kubernetes 集群操作的概念、局限性与执行边界，通过理论构建直觉，明确本课程不进行实际集群交互。

核心解释

集群执行与概念模拟的边界
Kubernetes 的核心在于声明式 API（Declarative API）。在教学中，我们通过理解控制循环（Control Loop）来模拟集群状态的达成，但并不实际调用 API Server 或操作物理节点。真实集群执行涉及复杂的认证、授权、网络通信与资源调度，而概念理解重点在于从 '预期状态' 到 '实际状态' 的调和过程。

例子

假设一个 Deployment 的声明文件，集群 Controller 会观察并触发副本创建，教学中我们将其抽象为 '状态转换图' 而非执行命令。

误区

认为学习 Kubernetes 必须随时连接到远程真实集群，否则无法理解其运作机制。

总结

本章节仅限于概念解析。学习者应专注于声明式模型与控制循环的逻辑，而非寻求实时集群的交互验证。
