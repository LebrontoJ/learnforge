HTTP 缓存的核心概念

1. 基本原理

HTTP 缓存是位于客户端或代理服务器上的存储机制，用于保存服务器响应的副本。当再次请求同一资源时，系统通过判断缓存的有效性，直接返回本地副本而非重新发起网络请求，从而大幅降低延迟并减轻服务器负载。

例子：用户首次访问网页图片时，浏览器通过网络下载并存储；第二次访问时，浏览器发现该图片在有效期内，直接从本地磁盘读取。

2. 常见误区

误区：认为缓存仅仅是浏览器的行为。

事实：HTTP 缓存实际上包含私有缓存（浏览器）和共享缓存（如 CDN、代理服务器）。

3. 总结

理解缓存的边界在于区分“有效性检查”与“直接使用缓存”。缓存不仅是提升性能的手段，也是构建高效网络架构的基石。
