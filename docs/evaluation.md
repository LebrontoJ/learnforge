## 限制与发布状态

- 原始证据见 artifacts/evaluation/results.json 与其 data/artifacts 下的 HTML、报告、桌面/移动截图。重跑命令：npm run eval。
- 故意持续失败的按钮与死循环案例应在两轮修复后仍失败；这是停止条件的成功，不计为内容通过。
- 固定摘要由开发者编写，引用链接没有被当作已实时读取页面。引用支持人工抽样：0 条，未验收。
- 不支持真实后端执行的案例只交付讲稿，语义未验证。
- 此处的 Counter 参考算法不等同 Prometheus rate 的外推实现。
- P95 仅描述本机的小样本批次，不代表服务容量。
- **PRD 发布门槛尚需：配置真实模型/搜索密钥，运行固定快照的模型 A/B 与真实搜索端到端评测；独立人工内容审查及保留集评测。** 工程演示通过不能替代这些门槛。
