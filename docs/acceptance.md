## 已执行验证

- `npm test`：14 项单元回归通过（新增限流、有限重试、预算与取消）。
- `npm run check`：所有 JavaScript 文件语法检查通过。
- `npm run test:integration`：模型 HTTP 适配、Schema 修正、局部修复、复验、版本保留、停止、队列取消与跨站写保护通过；使用本地模拟模型，不调用真实模型。
- `npm run test:security`：未授予 fetch/storage/location/postMessage/真实 DOM、Function 构造器逃逸、Worker 死循环终止和后续恢复通过。
- `npm run test:e2e`：桌面与移动 UI、课程确认、LRU 实际交互、刷新恢复与证据查看通过，保存视频。
- `npm run eval`：22 案例真实浏览器工程评测，10/12 尝试修复的案例最终通过，2 个持续失败案例按上限停止，0/12 检测到回归。详见独立报告。

- `npm run eval:live -- --resume`：20/20 固定资料案例执行完成；真实模型 100 次 HTTP 尝试（35 次拒绝），147,589 个已报告 Token；首次行为 0/16、最终行为 12/16、技术规则 8/16。12/20 产物通过工程检查，普通讲稿语义仍未自动验证。

当前已接入 Gemini 免费项目并完成真实模型固定资料批次；真实搜索、人工内容与保留集验收仍未完成，因此 **不能宣称已达到 PRD §7.4 的全部发布门槛**。真实搜索、真实大纲 UI、内容质量、人工引用支持与保留集结果应补齐后再发布为 M1 完全验收版本。先用 `.env` 配置，再运行 `eval:live` 和 `eval:e2e`，保留完整原始产物；新增独立人工审查记录，不在结果未支持时宣称质量提升。
